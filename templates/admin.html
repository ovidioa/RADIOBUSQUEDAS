Instrucciones Importantes
Procesamiento de XML
  • • Los archivos XML deben estar en el directorio especificado
  • • El sistema procesará todos los archivos .xml encontrados
  • • Los archivos duplicados se actualizarán automáticamente
  • • Puedes procesar el mismo directorio múltiples veces de forma segura
Gestión de Base de Datos
  • • Usa "Limpiar Base de Datos" solo cuando necesites empezar de cero
  • • Esta acción eliminará TODOS los registros existentes
  • • No hay forma de recuperar los datos una vez eliminados
  • • Considera hacer una copia de seguridad antes de limpiar
